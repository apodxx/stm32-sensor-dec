# STM32 SensorDeck

**STM32F103 多传感器监测台**：0.96" OLED 显示、MAX30102 心率血氧、DHT11 温湿度、GL5516 光照、MPU6050 六轴、槽型光耦测速，外加 SG90 舵机与有源蜂鸣器，旋钮切页。
代码按**驱动 / 界面 / 调度**分层，新增传感器或页面时不需要动已有模块。

> 源码：<https://github.com/apodxx/stm32-sensor-dec>

## 快速开始

```bash
git clone https://github.com/apodxx/stm32-sensor-dec.git
cd stm32-sensor-dec
cmake --preset debug
cmake --build build/debug/build
```

烧录 `build/debug/build/stm32_sensor_deck.hex`，ST-Link 接 SWDIO/SWCLK/GND/3.3V 即可。

## 1. 功能

| 页面 | 内容 | 刷新 |
|---|---|---|
| 生命体征页 | 心率 bpm、血氧 %、PPG 波形、手指状态 | 25 fps |
| 温湿度页 | DHT11 温度（℃）、湿度（%RH） | 25 fps，数据 2 s 更新一次 |
| 亮度页 | 亮度百分比、亮度条、电压、等级 | 25 fps，数据 200 ms 更新一次 |
| 加速度页 | 三轴加速度（g）、芯片温度 | 25 fps，数据 100 ms 更新一次 |
| 转速页 | 电机转速（RPM） | 25 fps，数据 500 ms 更新一次 |

五个页面用**旋转编码器**切换（`ui.c` 里 `UI_AUTO_ROTATE` 改成 1 可恢复 5 秒自动轮播）。

> ⚠️ 血氧是基于经验公式的估算值，仅供学习演示，**不能用于医疗判断**。

## 3. 接线

### 3.1 总览

```
                    ┌──────────────┐
       3.3V ────────┤ VCC      OLED ├──── PB10 (SCL)   ┐ 同一条 I2C2
        GND ────────┤ GND          ├──── PB11 (SDA)   ┘ 总线并联
                    └──────────────┘
                    ┌──────────────┐
       3.3V ────────┤ VIN   MAX30102├──── PB6 (SCL)    ┐ 独立 I2C1
        GND ────────┤ GND          ├──── PB7 (SDA)    ┘ 与 OLED 分开
                    │ INT/RD/IRD   │  全部悬空
                    └──────────────┘
                    ┌──────────────┐
       3.3V ────────┤ VCC      DHT11├──── PB0 (DATA)
        GND ────────┤ GND          │
                    └──────────────┘

       3.3V ──[GL5516]──┬── PA0 (ADC1_IN0)
                        │
                     [10kΩ]
                        │
                       GND
```

### 3.2 OLED（SSD1306，I2C2）

| OLED | 开发板 | 说明 |
|---|---|---|
| GND | GND | |
| VCC | 3.3V | |
| SCL | **PB10** | I2C2_SCL |
| SDA | **PB11** | I2C2_SDA |

模块自带上拉电阻；若用裸屏，SDA/SCL 各接 4.7k~10k 到 3.3V。

### 3.3 MAX30102（I2C1，独立总线）

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| VIN | 3.3V | 1.8~5V 均可，统一 3.3V 最稳 |
| GND | GND | 有两个 GND 时都接 |
| SCL | **PB6** | I2C1_SCL（血氧专用） |
| SDA | **PB7** | I2C1_SDA（血氧专用） |
| NT (INT) | 悬空 | 本工程用轮询，不用中断 |
| RD | **悬空** | 红光 LED 阴极，芯片手册明确“一般不接” |
| IRD | **悬空** | 红外 LED 阴极，同上 |

- I2C 地址 **0x57**（HAL 里写 `0xAE`），走独立总线 I2C1，与 OLED 互不影响；
- 模块上的 **3 位焊盘**是 I2C 上拉电平选择，主控 3.3V 时短接到 **3.3V 端**；
- 不要给 VIN 接 5V 的同时让 OLED 用 3.3V，总线电平会被拉高。

### 3.4 DHT11（单总线）

| DHT11 | 开发板 | 说明 |
|---|---|---|
| VCC（1 脚） | 3.3V | 3.3~5.5V 均可，**统一 3.3V** 免去电平问题 |
| DATA（2 脚） | **PB0** | 需要 4.7k~10k 上拉到 3.3V |
| NC（3 脚） | 悬空 | 裸传感器才有 |
| GND（4 脚） | GND | |

- 3 针模块一般已带板载上拉，直接插杜邦线即可；
- 裸传感器建议外接 4.7k~10k 上拉：代码在释放总线时会切到「输入 + 内部上拉」（约 40k），短线下通常也能读，但长线或干扰环境下必须外加电阻；
- DHT11 两次读取间隔必须 ≥1s，本工程用 **2s**；
- 上电后需要约 1s 稳定，代码里第一次读取延后 1s。

### 3.5 光敏电阻 GL5516（ADC）

光敏电阻是**两端器件**，需要串一个固定电阻分压才能接 ADC：

```
3.3V ──[GL5516]──┬── PA0 (ADC1_IN0)
                 │
              [10kΩ]
                 │
                GND
```

| 接法 | 说明 |
|---|---|
| GL5516 一端 | 3.3V |
| GL5516 另一端 + 10kΩ 一端 | **PA0**（分压中点） |
| 10kΩ 另一端 | GND |

- 光照越强 → 光敏电阻阻值越小 → PA0 电压越高 → ADC 值越大；
- **裸光敏电阻**（2 脚）必须自己加 10k 分压电阻；
- 若买的是**带比较器的模块板**（3~4 脚，标 AO/DO）：`VCC→3.3V`、`GND→GND`、`AO→PA0`，`DO` 悬空不用（板载已有分压和电位器）；
- ⚠️ PA0 是模拟脚，**不耐 5V**，模块千万别用 5V 供电。

### 3.6 ST-Link（SWD）

| ST-Link | 开发板 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V | 3.3V（板子已 USB 供电时可不接） |

BOOT0 跳线保持 0（从 Flash 启动）。

### 3.7 舵机 SG90（PWM）

| SG90 | 接到 | 说明 |
|---|---|---|
| 棕/黑（GND） | GND | **必须和单片机共地** |
| 红（VCC） | **5V** | 板子的 5V 引脚，或外部 5V |
| 橙/黄（信号） | **PA1** | TIM2_CH2，50Hz PWM |

```
SG90 信号 ──── PA1 (TIM2_CH2)
SG90 电源 ──── 5V ──┬── 100~470uF ── GND
SG90 地   ──── GND ─┘
```

- ⚠️ **千万不要接 3.3V**：SG90 堵转电流可达 700mA，板载 3.3V 稳压器扛不住，会掉压把单片机一起复位；
- 用外部 5V 供电时，**GND 必须和开发板连在一起**，否则 PWM 没有参考地，舵机会乱抖；
- 建议在舵机电源两端并一个 100~470µF 电解电容，抑制启动瞬间的电压跌落；
- 信号 3.3V 电平 SG90 一般能识别；如果出现抖动/不响应，可串 1k 电阻并在信号线上加 10k 上拉到 5V。

### 3.8 有源蜂鸣器（GPIO）

| 蜂鸣器 | 接到 | 说明 |
|---|---|---|
| VCC | 5V | 3.3V 模块就接 3.3V |
| GND | GND | |
| I/O（控制脚） | **PA2** | 普通推挽输出 |

- **有源**蜂鸣器内部自带振荡电路，**给高电平就响**，不需要 PWM 或频率；
- 3 针模块板载三极管，PA2 可以直接驱动；如果是 **2 脚裸蜂鸣器**，不能直连 GPIO（电流可能超 20mA），要加 NPN 三极管（见 `buzzer.c` 顶部注释）；
- 少数模块是**低电平触发**，把 `buzzer.h` 里的 `BUZZER_ACTIVE_LOW` 改成 `1` 即可。

### 3.9 MPU6050 六轴（I2C1，与血氧模块共用）

| MPU6050（GY-521） | 接到 | 说明 |
|---|---|---|
| VCC | **3.3V** | 统一 3.3V；用 5V 会把总线拉到 5V |
| GND | GND | |
| SCL | **PB6** | 与血氧模块同一条 I2C1 |
| SDA | **PB7** | 与血氧模块同一条 I2C1 |
| AD0 | 悬空 | 悬空=0x68，接 3.3V=0x69（固件两个地址都会试） |
| INT | 悬空 | 本工程轮询 |

- I2C 地址 **0x68**，和 MAX30102 的 0x57 不冲突，所以可以共用一条总线；
- GY-521 板子自带 3.3V LDO 和电平转换，**但供电要用 3.3V**：接 5V 时板载上拉会把 SCL/SDA 拉到 5V，会通过总线灌到血氧模块和单片机里。

### 3.10 测速模块（槽型光耦）

| 模块 | 接到 | 说明 |
|---|---|---|
| VCC | 3.3V（或 5V） | PB1 是 5V 容忍脚，用 5V 供电也安全 |
| GND | GND | |
| DO | **PB1** | EXTI1，下降沿计数 |
| AO | 悬空 | 模拟输出，本工程不用 |

```
码盘装在电机轴上，夹在槽型光耦的槽口中间
每转过一个槽 -> DO 输出一个下降沿 -> PB1 中断计数
```

- 码盘槽数在 `speed.h` 的 `SPEED_SLOTS` 里设，**默认 20 槽**（最常见的规格），换码盘只改这个数；
- 统计窗口 500ms，转速 = 脉冲数 × 120 / 槽数。

### 3.11 旋转编码器（旋钮切页）

| 编码器模块 | 接到 | 说明 |
|---|---|---|
| GND | GND | |
| VCC | 3.3V | |
| A | **PA5** | A 相（EXTI5） |
| B | **PA6** | B 相（EXTI6） |
| C | **GND** | 多数模块的 C 是公共端 |

```
编码器 A/B 输出相差 90° 的方波，单片机按相位顺序判断正转/反转
一个机械档位 = 4 个计数（4 倍频）
```

- A、B 都开了**内部上拉**（约 40k），模块没带上拉电阻也能用；
- C 脚如果其实是按键，接地只是让按键失效，不影响旋转；
- 正转/反转方向反了：把 A、B 两根线对调即可，不用改代码。

> 如果你手上其实是**电位器**（转到两端会卡住、型号里带 10k），那它不是编码器：
> 电位器两端接 3.3V/GND、滑片接 PA4，用 `knob.c`（工程里也保留了，把 `main.c` 里的
> `Encoder_Init()` 换成 `Knob_Init()` + `Knob_Scan()` 即可）。

### 4.2 依赖关系

```
main.c
 ├── oled     （底层屏幕驱动，只被 ui.c 调用，走 I2C2）
 ├── ui       -> max30102, dht11, light, oled
 ├── max30102（走 I2C1）
 ├── dht11    （只依赖 HAL GPIO）
 ├── light    （只依赖 ADC 寄存器）
 ├── servo    （只依赖 TIM2）
 ├── buzzer   （只依赖 GPIO）
 ├── mpu6050  （走 I2C1，与 max30102 共用总线）
 ├── speed    （只依赖 GPIO 外部中断）
 ├── knob     -> adc1（电位器备选方案）
 ├── encoder  （A/B 相正交解码，EXTI5/6）
 ├── adc1     （ADC1 外设，光敏和旋钮共用）
 └── i2c1     （PB6/PB7 总线初始化）
```

**两条 I2C 总线**：

| 总线 | 引脚 | 挂的设备 |
|---|---|---|
| I2C2 | PB10 / PB11 | OLED |
| I2C1 | PB6 / PB7 | MAX30102（0x57）、MPU6050（0x68） |

- **驱动层**（max30102 / dht11 / light）只负责采数据，不碰屏幕；
- **界面层**（ui）只负责画，不碰 I2C / ADC；
- **调度层**（main）只负责按周期调用，不含业务逻辑。

这样换屏幕、换传感器、加页面都互不影响。

### 4.3 主循环

```c
while (1)
{
    now = HAL_GetTick();

    if (now - lastPollTick  >= 10)   { lastPollTick = now;  MAX30102_Process(); }  // 10ms 读 FIFO
    if (now - lastEnvTick   >= 1000) { lastEnvTick = now;   DHT11_Task(); }        // 1s 调一次（内部限速 2s）
    if (now - lastLightTick >= 200)  { lastLightTick = now; Light_Task(); }        // 200ms 采一次，8 次平均
    if (now - lastMpuTick   >= 100)  { lastMpuTick = now;   MPU6050_Task(); }       // 100ms 读一次六轴
    if (now - lastSpeedTick >= 100)  { lastSpeedTick = now; Speed_Task(); }         // 500ms 统计一次转速

    if (now - lastKnobTick  >= 50)   { /* 旋钮编码器：档位变化 -> UI_SetPage() */ }  // 切页

#if SERVO_DEMO_SWEEP
    if (now - lastServoTick >= 20)   { lastServoTick = now; /* 角度 ±1° 后 SetAngle */ }
#endif

    Buzzer_Task();                          // 处理鸣叫结束
    if (MAX30102_TakeBeatEvent())
        Buzzer_Beep(30);                    // 心跳打拍子

    UI_Task();                              // 25fps 刷屏 + 5s 换页
}
```

## 5. 模块 API

### 5.1 MAX30102

```c
#include "max30102.h"

MAX30102_Init();                 // 返回 0 成功；失败后 Process() 每秒自动重连

// 主循环每 10ms 调用
MAX30102_Process();

// 取数据
const MAX30102_Data *d = MAX30102_GetData();
d->heartRate;   // bpm，0 表示无效
d->spo2;        // %，0 表示无效
d->fingerOn;    // 1 = 检测到手指
d->ready;       // 1 = 传感器在线
d->usingRed;    // 1 = 红外通道无信号，正在用红光测心率
d->rawRed;      // 红光原始值（18 位）
d->rawIr;       // 红外原始值（18 位）
d->waveP2P;     // 波形峰峰值

// 取波形（旧 -> 新）
uint32_t wave[128];
uint8_t n = MAX30102_CopyWave(wave, 128);
```

**通道自适应**：正常模块两路都有信号 → 用红外测心率、双路算血氧；
若红外通道无信号（LED 损坏或克隆芯片）→ 自动切到红光测心率，`spo2` 保持 0（界面显示 `--%`）。

### 5.2 DHT11

```c
#include "dht11.h"

DHT11_Init();      // 配置 PB0 + 使能 DWT 微秒延时

// 主循环每 1s 调用一次即可（内部限速 2s）
DHT11_Task();

const DHT11_Data *env = DHT11_GetData();
env->temperature;  // ℃，int8_t，可能为负
env->humidity;     // %RH
env->valid;        // 1 = 数据有效（连续失败 3 次才置 0）
env->failCnt;      // 连续失败次数
```

换引脚：改 `dht11.h` 里的 `DHT11_PORT` / `DHT11_PIN` 即可，时钟使能会自动匹配。

### 5.3 光照 GL5516

```c
#include "light.h"

Light_Init();       // PA0 模拟输入 + ADC1 初始化（寄存器操作）

// 主循环每 200ms 调用一次（内部 8 次平均）
Light_Task();

const Light_Data *lt = Light_GetData();
lt->raw;            // ADC 原始值 0~4095
lt->millivolt;      // 换算电压 0~3300 mV
lt->percent;        // 0~100，已按人眼感觉分段映射
lt->valid;          // 1 = 转换正常
```

- 亮度百分比不是线性电压：光敏电阻阻值随照度指数变化，代码用标定点做了分段映射，
  大致对应 `10% ≈ 1 lux、40% ≈ 10 lux、70% ≈ 100 lux、100% ≈ 1000 lux`；
- 需要真实照度时可自己换算：`R = 10k × (3300 − mV) / mV`，再用 GL5516 曲线
  `lux ≈ (32700 / R)^1.495`（R 单位 Ω，个体差异较大，仅供参考）；
- 换引脚要同时改 `light.h` 的 `LIGHT_ADC_PIN` 和 `light.c` 里的 ADC 通道号。

#include "ui.h"

UI_Init();

UI_SetPage(UI_PAGE_CLIMATE);  // 手动切页

### 5.5 SG90 舵机

```c
#include "servo.h"

Servo_Init();            // PA1 输出 50Hz PWM，上电回中位 90°

Servo_SetAngle(0);       // 0~180°，超出自动限幅
Servo_SetAngle(90);
Servo_SetAngle(180);

Servo_SetPulse(1500);    // 也可以直接给脉宽，500~2500us
```

- 定时器：TIM2，预分频 72 → 1MHz 计数，ARR=20000 → 20ms 周期，CCR 直接就是脉宽 us；
- `main.c` 里的 `SERVO_DEMO_SWEEP` 宏控制开机自动扫动，设成 `0` 就只保留接口；
- 想让光照控制舵机，可以在主循环里写：
  ```c
  Servo_SetAngle(Light_GetData()->percent * 180 / 100);
  ```

> 工程原先没启用 HAL 的 TIM 模块，我在 `stm32f1xx_hal_conf.h` 里打开了
> `HAL_TIM_MODULE_ENABLED`。如果用 CubeMX 重新生成代码，记得重新勾选 TIM2 的 PWM
> 通道（或在生成后手动把这一行加回去），否则 `servo.c` 会编译不过。

### 5.6 有源蜂鸣器

```c
#include "buzzer.h"

Buzzer_Init();        // PA2 推挽输出，默认关闭
Buzzer_On();          // 一直响
Buzzer_Off();         // 停

Buzzer_Beep(30);      // 非阻塞：响 30ms 后由 Buzzer_Task() 自动关
Buzzer_Task();        // 主循环里反复调用
```

主循环里已经接好了两件事：

1. 开机响两声（确认蜂鸣器接对）；
2. **每次检测到有效心跳响 30ms**，像医院监护仪那样打拍子——用 `MAX30102_TakeBeatEvent()` 取事件，UI 不会把它吃掉。

不想要心跳提示音就把 `main.c` 里的 `BUZZER_BEAT_SOUND` 设成 `0`。

### 5.7 MPU6050 六轴

```c
#include "mpu6050.h"

MPU6050_Init();        // 0 = 成功；失败后 Task() 每秒自动重连
MPU6050_Task();        // 主循环每 100ms 调用一次

const MPU6050_Data *m = MPU6050_GetData();
m->ax, m->ay, m->az;   // 加速度，单位 g（平放时 az ≈ 1.00）
m->gx, m->gy, m->gz;   // 角速度，单位 °/s
m->tempC;              // 芯片内部温度（不是环境温度，会偏高几度）
m->ready;              // 1 = 器件在线
```

- 量程：加速度 ±2g（16384 LSB/g）、陀螺仪 ±250°/s（131 LSB/°/s）；
- 采样率 100Hz，DLPF 44Hz；
- 和血氧模块共用 I2C1（地址 0x68 / 0x57 不冲突），不需要额外引脚；
- 支持 WHO_AM_I 为 `68/70/71/72/73/74/98` 的兼容芯片，温度公式按型号自动切换
  （MPU6050 与 MPU6500/6515 的换算不同，用错会偏差十几度）。

### 5.8 测速模块（槽型光耦）

```c
#include "speed.h"

Speed_Init();          // PB1 下降沿中断
Speed_Task();          // 主循环每 100ms 调用，内部按 500ms 窗口统计

const Speed_Data *s = Speed_GetData();
s->rpm;                // 转速（转/分）
s->pulsesPerSec;       // 每秒脉冲数
s->totalPulses;        // 累计脉冲
s->active;             // 1 = 最近窗口内有脉冲
```

- 中断里只做 `pulseCnt++`，窗口结束时关中断读一次再清零，不会漏脉冲；
- 转速 = `脉冲数 × 60000 / (窗口ms × 槽数)`，20 槽时 1 转 = 20 个脉冲；
- 窗口 500ms 意味着**响应约半秒**，转速越快越准；很低速时（<30RPM）分辨率会变粗。

### 5.9 旋转编码器（切页）

```c
#include "encoder.h"

Encoder_Init();          // PA5/PA6 双边沿中断 + 上拉
Encoder_GetCount();      // 4 倍频计数（一个档位 = 4）
Encoder_GetDetents();    // 档位 = count / 4
Encoder_Reset();
```

主循环里的用法（已写好）：

```c
int16_t d = Encoder_GetDetents();
if (d != lastDetent)
{
    int16_t p = (int16_t)UI_GetPage() + (d - lastDetent);
    lastDetent = d;
    while (p < 0) p += UI_PAGE_COUNT;
    UI_SetPage((UI_Page)(p % UI_PAGE_COUNT));
}
```

- 正转下一页、反转上一页，到两端自动回绕；
- 解码用 4 状态表（`table[(prev<<2)|cur]`），抖动和非法跳变都计 0，不会乱跳；
- 如果一档跳两页，说明你的编码器每档只有 2 个计数，把 `Encoder_GetDetents()` 里的 `/4` 改成 `/2`。

## 6. 界面说明

界面全中文，使用 `font.c` 里的 16×16 中文字库（40 字），数字用 `afont16x8` / `afont24x12` 补位。

### 生命体征页

```
心率072  血氧98%
┌──────────────────┐
│     PPG 波形      │
└──────────────────┘
       请放手指
```

- 无手指时底部提示「请放手指」，检测到手指后自动消失；
- 血氧需要红光 + 红外两路，红外故障时固定 `--%`；
- 传感器掉线时整页显示「传感器未连接 / 检查接线」，每秒自动重连。

### 温湿度页

```
 温度 26 ℃
 湿度 58 %
```

- 数字用 24×12 大字体；
- 连续 3 次读取失败时整页显示「读取失败 / 检查接线」。

### 加速度页

```
加速度 28℃
X +0.12
Y -0.03
Z +1.00
```

- 三轴加速度单位是 **g**，平放时 Z ≈ +1.00，翻过来 ≈ −1.00；
- 右上角是 MPU6050 的**芯片温度**（不是环境温度，通常比室温高 2~5℃）；
- 陀螺仪数据在 API 里（`m->gx/gy/gz`），没有放到屏幕上。

**未连接时的诊断页**：

```
传感器未连接
   I2C 57 68
   ID 68
```

- `I2C` 后面是扫描到的地址（最多显示 3 个）。只有 `57` 说明 MPU 完全没应答（接线/供电）；
  出现 `68` 但页面仍报错，看 `ID`；
- `ID` 是 WHO_AM_I 读到的值，只有下面这些会被接受（它们的寄存器映射兼容）：
  `68`=MPU6050、`70`=MPU6500、`71`=MPU9250、`72`=兼容片、`73`=MPU9255、`74`=MPU6515、`98`=ICM20689；
  其他值说明芯片型号不同（把值告诉我，我把判断放宽）；
- 代码会自动尝试 0x68 和 0x69 两个地址，AD0 接高也能用。

### 转速页

```
转速
 1234 RPM
```

- 大号数字是电机转速，窗口 500ms 统计一次；
- 码盘槽数不对会导致数值成比例偏差（20 槽码盘显示 1200，换成 12 槽还是显示 1200 就说明槽数设错了）。

> ⚠️ 字库里还缺 **「加」「速」「转」** 三个字（加速度页需要「加」「速」，转速页需要「转」「速」）。
> 把这三个字加进 `font.c` 的 `zh16x16` 即可；建议顺便一起加「陀」「螺」「仪」，以后做陀螺仪页就不用再生成。

### 亮度页

```
亮度 62%
[██████████░░░░░░]
电压 1.94V
      正常
```

- 大号数字是亮度百分比（0~100），下面是亮度条；
- 底部等级：`暗`（<10）/ `微亮`（<40）/ `正常`（<70）/ `明亮`。

> 字库里没有「光」字（生成时漏了），所以光照页标题用的是「亮度」。
> 需要「光照」的话，把 `光` 加进 `font.c` 的 `zh16x16` 再改 `ui.c` 里的字符串即可。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| OLED 全黑 | 查 PB10/PB11 是否接反、模块地址是 0x3C 还是 0x3D（改 `oled.c` 的 `OLED_ADDRESS`） |
| 屏幕显示 `传感器未连接` | 血氧模块走的是 **I2C1（PB6/PB7）**，不是 PB10/PB11；再查 VIN 是否 3.3V、SDA/SCL 是否接反、模块地址是否为 0x57 |
| 有波形但心率一直 `---` | 手指压太紧（阻断血流）或没盖住窗口；轻放、完全覆盖 |
| 波形是直线、心率测不到 | 红外 LED 不发光（模块故障/克隆芯片）。本工程会自动改用红光测心率；血氧无法测量，显示 `--%` |
| 温度湿度一直是 `--` | DHT11 没接上拉、DATA 不是 PB0、或两次读取间隔太短 |
| 温湿度偶尔 `ERR` | 单总线受干扰，属正常；连续 3 次失败才判无效 |
| 光照一直 `0%` / ADC 为 0 | 分压电阻没接、PA0 没接中点、或光敏电阻两端接反（两端接反只会让数值反向，不会为 0） |
| 光照一直 `100%` | 分压电阻阻值太小（比如用了 1k），换 10k 即可 |
| 光照数值乱跳 | ADC 采样脚走线太长，或分压中点悬空；把 PA0 的线缩短、共地即可 |
| 舵机不动 / 一直抖 | 90% 是供电：接了 3.3V 或没共地。必须用 5V、GND 相连、并加 100µF 以上电容 |
| 舵机转到头还在响 | 角度超出机械行程，把 0~180 收窄到 5~175 |
| 蜂鸣器不响 | 先听开机有没有两声：没有就查 PA2/VCC/GND；模块是低触发的话把 `BUZZER_ACTIVE_LOW` 改成 1 |
| 蜂鸣器一直响 | 引脚电平和模块极性反了，同上改 `BUZZER_ACTIVE_LOW` |
| 加速度页显示「传感器未连接」 | 看诊断页的 `I2C` 和 `ID`：只有 57 → MPU 没应答（VCC/GND/SCL/SDA）；有 68 但 ID 不对 → 芯片型号不同，把 ID 值告诉我 |
| 加速度数值不动 / 全是 0 | 初始化后没调用 `MPU6050_Task()`，或 I2C1 上另一个器件把总线拉死 |
| 转速一直是 0 | 码盘没夹进槽口、DO 没接 PB1、或模块没供电（模块上有指示灯，挡光时会亮） |
| 转速明显偏大/偏小 | `speed.h` 里的 `SPEED_SLOTS` 和实际码盘槽数不一致 |
| 旋钮完全没反应 | A/B 没接 PA5/PA6，或模块没供电；先量 A/B 静态电平，应为 3.3V（内部上拉） |
| 转一下跳好几页 | 编码器每档计数不是 4，把 `Encoder_GetDetents()` 里的 `/4` 改成 `/2` 或 `/1` |
| 转动方向相反 | 把 A、B 两根线对调即可 |
| 页面自己乱跳 | A/B 线太长或没共地，缩短并确认模块 GND 与开发板相连 |

## 9. 扩展：加一个新传感器 / 新页面

1. **新建驱动** `Core/Inc/xxx.h` + `Core/Src/xxx.c`，只暴露 `XXX_Init()` / `XXX_Task()` / `XXX_GetData()`；
2. 在 `CMakeLists.txt` 的 `target_sources` 里加一行；
3. 在 `main.c` 里初始化并按周期调用；
4. 在 `ui.h` 的 `UI_Page` 枚举里加一页，在 `ui.c` 里写 `UI_DrawXxx()` 并加入 `UI_Task()` 的分支。

> 绘制只用 `oled.h` 提供的接口（`OLED_PrintASCIIString` / `OLED_DrawLine` / `OLED_SetPixel` ...），
> 不要在其他模块里直接操作显存，保证“驱动不画屏、界面不碰硬件”。

## 10. 已知限制

- 血氧公式来自 Maxim 评估板的经验曲线，未做逐台标定，只能看趋势；
- MAX30102 采样率固定 100sps / 4 次平均（25Hz），心率响应约 1~2 秒；
- DHT11 精度 ±2℃ / ±5%RH，且刷新率只有 0.5Hz；
- GL5516 的亮度百分比是**相对值**，个体差异大，未做逐颗标定；
- 本工程没有按键，界面靠时间轮播；接按键后可调用 `UI_NextPage()` 改成手动切换。
