# 功能演示 · 口播稿

> 约 3 分半，口播 850 字左右。加粗是段落小标题（不用念），括号是动作（不用念）。

---

**开场｜先说之前那个**

之前我做过一个 STM32 的小项目：一块板子上挂了屏幕、心率、温湿度、光敏、六轴、测速、舵机、蜂鸣器，还有一个旋钮，五个页面拧着看。

做完就摆在桌上，一直开着。

**这次又加了什么**

后来我又给它配了个"脑袋"，一块 ESP32，上面装了会说话的 AI，现在它能听懂我讲话了。

于是我就琢磨：能不能让这个会说话的，去指挥那个会干活的。

现在就成了：我一张嘴，它动手。

**怎么分工**

分工也简单。底下这块负责动手，量温度、看亮暗、数心跳、转马达，都是它的活。而且它手脚挺利索，一边刷着屏幕，一边还能接着干活，从来不站着干等。

上面这块负责动嘴，听我喊它、听我说话、上网问 AI，再把答案念出来。

中间怎么搭上话呢？我给它俩定了一张"菜单"：上面这块知道底下这块能干哪几件事——开灯、开闸门、报温度。我一开口，它就从菜单上挑一样，交给下面去办。

**叫醒它**

"你好小智。"

（等它答应）

唤醒词是跑在本地的模型，不联网也能听见；真要回答，才上云。

**温湿度**

"现在房间多少度？"

这颗 DHT11 走的是单总线，一根线既供电又传数据，时序挺挑，所以读的时候我把中断关掉了。

**光照**

"现在亮不亮？"

（手遮一下）

光敏电阻和 10k 电阻分压送进 ADC。手一挡，阻值一变，数字马上掉。

**心率**

（手指按上传感器）

"我的心率多少？"

手指按上去，红光和红外照进皮肤，靠反射光的起伏数心跳。

这块模块的红外通道其实是坏的——我在固件里加了自动切红光，所以心率能测，血氧报不出来。

**加速度**

（拿起板子歪一下）

"板子放平了吗？"

六轴，平放的时候 Z 轴是一个 g，翻过来就是负一。

**转速**

（拨一下码盘）

"电机转多快？"

码盘挡光，光耦出脉冲，STM32 数脉冲。500 毫秒一个窗口，20 槽的盘转一圈算 20 个。

**一口气问**

"把所有数据念一遍。"

（等它念完）

九项一次说完，省得一项一项问。

**开灯**

"开灯。"

（灯亮）

"关灯。"

（灯灭）

灯接在 PA4 上，一颗 LED 加个 220 欧电阻。

**闸门**

"开闸门。"

（马达转 90 度）

"关闸门。"

（回原位）

舵机用的是 50Hz 的 PWM，脉宽 0.5 到 2.5 毫秒对应 0 到 180 度，我说开就是转 90 度。

平时它一动不动，只有我开口才转。

**用嘴换页**

"切到转速页。"

（屏幕跳页）

拧旋钮能换，动嘴也能换。

**结尾**

（镜头拉远）

这套东西加起来一百多块。

代码、接线图、还有一份两万多字的教程，都开源在 GitHub。

代码在群里，进群自动获取。

## 拍摄顺序（不含时间）

| 顺序 | 你要做什么 | 应该看到 |
|---|---|---|
| 1 | 整机俯拍，拧一下旋钮 | — |
| 2 | 插电 | 屏幕亮，小鸭子（不配旁白） |
| 3 | 拧 5 格旋钮 | 五页轮换 + 每格"嘀"（不配旁白） |
| 4 | 说「你好小智」 | 它答应 |
| 5 | 问温度 | 语音报数 |
| 6 | 问亮不亮，手遮一下 | 语音报数 |
| 7 | 手指按传感器，问心率 | 语音报数 |
| 8 | 歪一下板子，问平不平 | 语音报数 |
| 9 | 拨码盘，问转速 | 语音报数 |
| 10 | 说"念一遍" | 一口气报完 |
| 11 | 开灯、关灯 | 灯亮/灯灭 |
| 12 | 开闸门、关闸门 | 马达转 90°/回位 |
| 13 | 说"切到转速页" | 屏幕跳页 |
| 14 | 结尾 | 群二维码定格 2 秒 |

## 录制提醒

1. 每个功能先单独试一遍，尤其"开灯""开闸门"；
2. 等它"叮"一声再开口，别抢话；
3. 某一步没反应别停，接着说下一句，后期剪掉；
4. 结尾二维码定格 2 秒。
