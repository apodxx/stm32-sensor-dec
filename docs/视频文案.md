# 一、视频口播稿（约 640 字，2 分 30 秒）

一块 STM32，一块 OLED，再加一堆十块钱的传感器，能做出什么？

看这个，桌面上的小型监测台。

五个页面，旋转编码器一拧就切换。

第一页，心率血氧。手指放上去，波形和心率实时显示出来。还有一个小设计：每检测到一次心跳，蜂鸣器会跟着响一下，像监护仪那样。

第二页，温湿度，用大号数字显示。

第三页，光照强度，下面有一条亮度条。

第四页，六轴加速度。平放的时候，Z 轴正好是一个 g。

第五页，电机转速。码盘一转，RPM 立刻显示出来。

主控是最常见的 STM32F103C8T6，也就是 Blue Pill。所有模块加起来不到一百块。

接线分了两条 I2C：OLED 独占一条，血氧和六轴共用另一条，地址不冲突，接在一起就行。

温湿度走单总线，光敏电阻走 ADC，测速用外部中断，舵机和蜂鸣器各占一个 IO。

整套接线，一张表就能说清楚。

代码按三层结构编写：驱动层只负责采集数据，界面层只负责绘制，主循环只负责按时间调度。

所以想加一个新传感器，只要写一个 .c 文件，再在界面上加一页，其它模块一行都不用动。

主循环里没有使用任何延时函数，因此二十五帧刷屏和一百赫兹采样可以同时运行。

开发过程中也遇到几个问题，都写进文档了。

比如这块血氧模块，红外通道是坏的。固件检测到以后会自动切换到红光来测心率；虽然此时没有血氧数据，但心率依然能正常测量。

再比如这块六轴，其实不是 MPU6050，是 MPU6515。识别出 ID 之后，温度公式也得跟着换。

完整的代码、接线表，还有一份两万字的搭建教程，都已经开源在 GitHub，MIT 协议，可以随意修改和使用。
