# 功能演示 · 逐字稿（定稿）

> 引号里是对板子说的话，念完停一下等它回应。

---

之前做过一个 STM32 的小项目：把一堆模块接在开发板上，用一个旋钮切换，看每个模块的效果。

今天在这基础上，给它加了个"脑袋"——一块 ESP32，加上语音 AI。

现在我只要说啥，它就能做啥。

话不多说，演示一下。

"你好小智。"

"开灯。"

"关灯。"

"现在房间多少度？"

"现在亮不亮？"

"我的心率多少？"

"板子放平了吗？"

"电机转多快？"

"把所有数据念一遍。"

九项一次返回，省得一项一项问。

刚才那颗灯，就接在 STM32 的 PA4 上，一颗 LED 串个 220 欧的电阻。

"开闸门。"

"关闸门。"

这两块板子怎么分工？其实特别简单。

STM32 是"手脚"：屏幕、传感器、舵机、蜂鸣器、旋钮，全都接在它身上，它负责读数据、刷屏幕、按指令动手。

ESP32 是"耳朵和嘴巴"：它身上不接任何传感器，只负责听我说话、把我说的送到云端、再把云端的回答念出来。

它俩靠一根串口线连着，就三根线：一根发、一根收、一根地。我说的每句话，ESP32 会翻成一条很短的文字命令发给 STM32，比如"开灯"两个字；STM32 干完活，回一句 OK。

就这么简单。

这个项目拿去做毕设、做智能家居、或者当个爱好都合适。

整套硬件一百多块，代码和两万多字的教程都开源在 GitHub 和粉丝群里。
